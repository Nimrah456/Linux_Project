# 🖥️ College Computer Laboratory Management System

## 📌 About the Project
A Linux-based mini-project developed using **Bash Shell Scripting** to simplify college computer laboratory management through automation, system administration, storage management, and security utilities.

## ✨ Features
- **System Administration:** User, package, and service management.
- **Storage & Backup:** Disk inspection, backup, and recovery.
- **Automation & Security:** Cron jobs, firewall, and access control.
- **Monitoring & Testing:** System monitoring, testing, and logs.

## 🛠️ Technologies Used
- Ubuntu Linux
- Bash Shell Scripting
- Linux Commands
- Cron
- Git and GitHub

## ⚙️ Installation & Execution

```bash
git clone https://github.com/Nimrah456/Linux_Project.git
cd Linux_Project/Integrated_Project
chmod +x main.sh
sudo ./main.sh
```

## 👥 Team Structure
1. System Administration
2. Storage & Backup Management
3. Automation & Security
4. Testing & Documentation

## 🎯 Objective
To demonstrate practical Linux system administration, automation, security, and backup management through a modular, menu-driven application.
