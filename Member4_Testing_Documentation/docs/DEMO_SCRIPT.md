# Demo Script (about 10 minutes)
1. Member 4 introduces the project and runs `bash tests/run_tests.sh`.
2. Member 1: `sudo ./main.sh` -> create users, install packages, shared folder, show network.
3. Member 2: show `lsblk` and `pvs/vgs/lvs`, take backup, delete a file, restore it.
4. Member 3: schedule cron, show firewall and permission audit.
5. Member 4: generate the report (Menu 7 -> 4) and show the activity log.
6. Member 4 coordinates questions and directs each to the owner.
